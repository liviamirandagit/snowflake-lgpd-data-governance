# Governança de Dados e LGPD no Snowflake 🔒

Implementando a LGPD na nuvem: governança na prática com o Snowflake Data Cloud.

-> Recursos Implementados
* RBAC (Role-Based Access Control): Gerenciamento por papéis (`ACCOUNTADMIN` vs `PUBLIC`).
* Dynamic Data Masking: Anonimização parcial de CPF e E-mail.
* Differential Privacy (Ruído Estatístico): Variação percentual dinâmica na coluna de Salário.
* Row Access Policy (RAP): Filtragem em nível de linha para ocultação automática de registros restritos/VIPs.
